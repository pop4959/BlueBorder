# BlueBorder
Displays the vanilla world border in BlueMap.

Builds are available through [GitHub Actions](https://github.com/pop4959/BlueBorder/actions).

## Usage

Simply install BlueBorder into BlueMap's `packs` folder.

When the plugin is loaded, markers will be added to BlueMap for all vanilla world borders.

You can force reload the markers or the config with the `/bluemap reload` command.

If you just changed the world border, you should run `/save-all flush` before reloading BlueMap,
to ensure the changes to the world border are saved to disk.
